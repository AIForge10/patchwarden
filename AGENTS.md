# AGENTS.md

## Git Commit and Attribution Rules

- Make all commits using the configured Git identity of the human developer responsible for the changes.
- Do not add `Co-authored-by` trailers for AI coding agents.
- Do not create commits, amend commits, rebase, or push unless explicitly requested.
- Prefer editing files, running tests, and presenting a summary of changes for human review.
- Never rewrite shared Git history or force-push without explicit approval.
