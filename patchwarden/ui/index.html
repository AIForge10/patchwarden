PatchWarden

Evidence-gated incident response

PatchWarden takes a signed crash alert, reproduces it in an isolated E2B sandbox, has NVIDIA Nemotron write a fix, and opens a human-review pull request only after trusted tests prove it. Then it challenges its own patch and looks for a second bug nobody reported.

The model proposes; trusted code decides. Every status on this page comes from a test, a hash or an invariant, never from model output.
